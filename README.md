# Waves

A React music player with playback controls, a song library, and auto-advance. Live at https://afterwaves.netlify.app/

## Stack

React 18, Vite, Sass, Font Awesome.

## Run locally

```bash
npm install
npm run dev      # dev server
npm run build    # production build in dist/
npm run preview  # serve the build
```

## Music

Tracks live in `public/music` and covers in `public/covers`; the song list is `src/data.js`.
Music by Marek Zielinski, Alex Morgan, and Yevhen Astafiev from [Pixabay](https://pixabay.com/music/).
